## Sound Files Required for Futuristic Popups

The following sound files are needed for the futuristic popup components:

1. `level-up.mp3` - For level up notifications
2. `xp-gain.mp3` - For XP increase notifications
3. `hp-change.mp3` - For HP change notifications
4. `quest-complete.mp3` - For quest completion notifications
5. `welcome.mp3` - For welcome popup
6. `input-click.mp3` - For input interactions in profile setup
7. `profile-confirm.mp3` - For profile setup confirmation

You can download royalty-free sound effects from sources like https://freesound.org/ and name them according to this list.
